# 声音注入 (Voice Injection)

## 原则

每个人物都有自己的声音指纹 (voice print)。在生成对话和内心独白时，必须遵循人物的声音特征。

## 声音维度

1. **词汇选择**：惯用词、方言、行业术语
2. **句式结构**：长句/短句、主动/被动、疑问/陈述偏好
3. **语气基调**：正式/随意、热情/冷淡、乐观/悲观
4. **节奏模式**：语速、停顿、重复模式
5. **情感标记**：表达情感的惯用方式
